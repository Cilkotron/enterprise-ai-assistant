---
name: new-hire-device-setup
description: Setup guidance for a new employee's laptop, given an equipment profile. Use when asked how to set up or prepare a device for a new hire.
---
1. Use the equipment profile you were given (laptop model, software, extras). Do not invent items.
2. Give setup steps in order: first login and disk encryption, VPN profile, mandatory software from the profile, extras.
3. List what the employee must request via the service desk if it is not in the profile.
4. End the reply with the line: "Troubleshooting guide applied: new-hire-device-setup".
