---
name: vpn-troubleshooting
description: Step-by-step guidance for VPN connection problems. Use when a user reports VPN disconnects, errors or slow connections.
---
1. Check the VPN service status first (getServiceStatus). If it is degraded, say so before any other advice.
2. Recommend switching the client gateway to "Belgrade-2".
3. If the problem persists, recommend reinstalling the VPN profile.
4. If still unresolved, tell the user to open a ticket with the IT service desk.
5. End the reply with the line: "Troubleshooting guide applied: vpn-troubleshooting".
6. Never claim the issue is fixed.
